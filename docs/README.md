# Qayd Website

This folder contains a one-page static website for Qayd.

Files:

- `index.html`: the page.
- `styles.css`: the shared visual system.
- `app.js`: theme, mobile menu, and copy buttons.
- `assets/qayd-logo.svg`: logo asset.

Preview:

```bash
python3 -m http.server 8080 -d docs
```

Then open `http://localhost:8080`.
